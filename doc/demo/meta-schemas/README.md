# On Schema-Based Meta-Analysis of RDF Data Sets

We provide supporting material for a paper submission at EKAW'2026 conference.

The basic information on getting started with the ViziQuer tool is available in
[ViziQuer wiki](https://github.com/LUMII-Syslab/viziquer/wiki).

The [ViziQuer tool main page](https://viziquer.lumii.lv) can be consulted for further information.

The environments referenced in the paper are available live 
on [ViziQuer Playground](https://viziquer.app). 
Registration with any e-mail formatted string is accepted.

There are demo environments created for logging in to 
[ViziQuer Playground](https://viziquer.app) during the review process. 
To share the accounts among different reviewers 
we suggest using the first one that is empty (has not created any project). 
Consider internal reviewer link in the submitted paper for further information.
